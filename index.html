Empleados y permisos

Cada persona debe tener su propio acceso. No compartas tu contraseña de administrador.

Para crear un empleado: en Supabase abre Authentication → Users → Add user y crea su correo/contraseña. Después copia su User UID y agrega un perfil en SQL Editor con el rol employee. Esta página muestra los perfiles ya creados; la clave secreta nunca se coloca aquí.
